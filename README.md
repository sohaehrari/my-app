# Weather Dashboard

A modern, responsive weather dashboard built with Next.js and React. Search for any city and view current weather conditions, hourly forecasts, and daily forecasts through a clean and intuitive interface.

## Live Demo

https://my-app-3n2h.vercel.app/

## Repository

https://github.com/sohaehrari/my-app

## Overview

Weather Dashboard provides a simple way to explore weather information for cities around the world.

The application focuses on:

- Current weather conditions
- Hourly forecasts
- Daily forecasts
- City search
- Popular city shortcuts
- Responsive design
- Modern user interface
- Authentication pages

## Features

### Weather Search

Search for a city and retrieve its weather information.

### Current Weather

View the current temperature and weather conditions for the selected location.

### Hourly Forecast

See how weather conditions and temperatures change throughout the day.

### Daily Forecast

View upcoming weather conditions and temperature information.

### Popular Cities

Quickly access weather information for commonly searched locations.

### Responsive Design

The interface is optimized for:

- Mobile devices
- Tablets
- Laptops
- Desktop screens

### Authentication

The project includes authentication pages for user registration and sign-in.
