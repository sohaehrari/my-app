🌤️ Skyora — Modern Weather Dashboard

Skyora is a modern, responsive weather dashboard built with Next.js and React, designed to make exploring weather conditions simple, fast, and visually engaging.

Search for any city around the world and get a beautiful overview of its current weather, hourly forecast, and upcoming daily forecast — all through a clean, responsive interface.

⚡ Getting Started

Clone the repository:

git clone https://github.com/sohaehrari/my-app.git


Move into the project directory:

cd my-app


Install dependencies:

npm install


Start the development server:

npm run dev


Open the application in your browser:

http://localhost:3000

🔑 Environment Variables

Create a .env.local file in the root directory and add the required weather API configuration:

WEATHER_API_KEY=your_api_key_here


Make sure environment variables are never committed to GitHub.
